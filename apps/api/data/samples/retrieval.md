# 检索链路设计

## 三级检索

1. 向量召回：把问题嵌入成向量，在 Milvus 中做近邻搜索。
2. 关键词召回：BM25 倒排索引，精确匹配领域术语与缩写。
3. 图召回：从知识图谱出发，沿实体关系做一跳扩展。

## 融合

三级召回的结果用 RRF（Reciprocal Rank Fusion）融合，公式为：

    score = Σ w_i / (k + rank_i)

其中 k 取 60，w_i 是通道权重，rank_i 是第 i 个通道内的排名。

## 重排

融合后的候选集再经过 Rerank 重排，把与问题语义最相关的块排到最前。
最终只保留 Top-5 作为生成上下文。
