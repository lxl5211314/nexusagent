# NexusAgent 企业知识平台 — 产品概述

## 定位与目标

NexusAgent 是一个面向企业的私有化知识智能体平台。它解决的核心问题是：
企业内部的制度、规范、产品文档、FAQ 分散在多个系统里，员工检索困难、
答案没有来源、AI 生成内容不可信。

平台把企业文档解析、分块、向量化之后，通过 Agentic RAG 的链路完成
「检索 — 推理 — 引用 — 拒答」的闭环，让每一次回答都能溯源。

## 核心能力

- 多格式文档解析：Markdown、TXT、CSV、JSON、YAML、日志、PDF、Word。
- Agentic RAG：向量 + 关键词混合召回，RRF 融合，重排，上下文压缩。
- 多智能体编排：主 Agent 意图理解与任务拆解，子 Agent 并行执行。
- 幻觉抑制：答案强制绑定引用来源块，低置信度拒答。
- 流式输出：SSE 推送思考链路、工具调用日志、步骤状态。

## 技术栈

后端使用 Python 3.13 + FastAPI + SQLAlchemy + LangGraph；检索链路使用
Milvus（向量）、BM25（关键词）、Neo4j（知识图谱）；前端使用 Vue3。

## 组件关系

前端使用 Vue3，通过 SSE 读取步骤状态与引用。
Spring Boot 网关调用 FastAPI 引擎，并透传租户、角色与 trace id。
检索链路包括向量召回、BM25 与图谱召回。
RRF 融合依赖于三路召回的排名，不依赖原始分数。
重排基于启发式打分，压缩上下文之后再交给模型。
引用校验属于答案生成之后的守卫，越界引用会触发重写。
审计日志存储于关系型数据库，与业务写入同事务。
组织架构包括部门、用户与角色，部门形成一棵层级树。
知识库属于某个部门，跨部门的库对无权限用户不可见。
文档块写入 Milvus 的向量集合，同时写入 Neo4j 的实体图。
