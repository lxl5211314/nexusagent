# 幻觉抑制机制

## 为什么需要幻觉抑制

大模型生成的内容可能包含事实错误，即「幻觉」。在企业知识场景里，
幻觉的代价很高：员工依据错误答案做决策。

## 三条防线

1. 引用强制绑定：生成的答案必须携带引用编号，引用编号必须指向
   实际检索到的知识块。没有引用或引用越界的答案会被拒绝并重写。
2. 低置信度拒答：当检索结果与问题相关性低于阈值时，系统拒绝回答，
   而不是强行生成。拒绝回答也是一种答案。
3. 检索上下文压缩：只把与问题最相关的知识块送入生成模型，
   降低无关上下文导致的幻觉。

## 评估口径

评估集按三个指标衡量：召回率、MRR、答案相关性。目标是把幻觉率
从 18% 降低到 5% 以下。
